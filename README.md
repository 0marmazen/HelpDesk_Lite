# HelpDesk Lite

## Overview

HelpDesk Lite is a lightweight internal support ticketing workspace designed to improve how employees submit, track, and resolve support requests.

This repository demonstrates a complete engineering delivery workflow, covering requirements analysis, project planning, AI-assisted development, engineering collaboration, and stakeholder communication.

---

## Project Goals

- Improve internal support request management
- Reduce duplicated requests
- Track ticket status clearly
- Support SLA monitoring and escalation
- Demonstrate modern software engineering practices

---
