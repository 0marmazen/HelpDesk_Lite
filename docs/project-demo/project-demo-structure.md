# Project Demo Structure

## Problem
Internal support requests were managed through emails and chat, making issue tracking, prioritization, and SLA monitoring difficult.

## Scope
HelpDesk Lite provides a centralized ticketing workspace where employees submit requests, agents manage tickets, and administrators monitor progress.

## Key Decisions
- Organized work using Jira.
- Applied AI in a controlled workflow.
- Used GitHub for collaboration.
- Planned implementation using Vibe Coding.
